# 🛒Blinkit-Dashboard
## Project Overview 
Made an interactive dashboard to analyse the performance of Blinkit on the basis of outlet location, Item type and outlet size.    
## Tools Used
Power BI, Power Query Editor, DAX, Charts and Slicers       
## What I did?  
- Cleaned and tranformed raw data using power Query editor.
- Used KPI cards to show the Total sales, Average ratings, Average Sales and No. of items company sells.
- Analysed sales trend for outlet eshtablishment year using line chart.
- To analyse outlet size and fat content i've used Donut chart.
- A matrix was used for shwoing item types against KPIs.
- Used a bar chart to show the comparision between different  item types towards sales contribution.
- Added Slicers for outlet location, Item type and outlet size toenable dynamic analysis.
